Comment nous avons stoppé le looping de Laguna S 2.1 sur notre DGX Spark

Diagnostic d'un « reasoning attractor », corrigé par deux paramètres vLLM (repetition_penalty + détection native d'ngrammes) — 0 timeout, 80 % de passes, une heure de calcul économisée par déploiement.
